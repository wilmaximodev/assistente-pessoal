# 🌟 Projeto MultiFuncional com Inteligência Artificial

Este projeto utiliza a API **Gemini AI** do Google para fornecer três funcionalidades principais:

✅ **Assistente de Receitas** 🍳 - Sugere receitas e dá dicas culinárias com base nos ingredientes fornecidos.  
✅ **Resumidor de Artigos Científicos** 📄 - Extrai texto de um PDF e gera um resumo conciso do conteúdo.  
✅ **Tradutor de Textos** 🌍 - Traduz documentos de português para inglês automaticamente.  

---

## 🚀 Funcionalidades

### 📖 1. Assistente de Receitas 🍳
Um chatbot interativo que fornece receitas com base nos ingredientes informados pelo usuário. Além disso, responde a dúvidas sobre culinária e dá dicas para o preparo de pratos.

**Tecnologias utilizadas:**
- **Python**
- **Gradio** (para interface gráfica interativa)
- **Gemini API** (modelo de IA para geração de respostas)

📌 **Como executar**:
```bash
pip install -r requirements.txt
python recipes.py
```
